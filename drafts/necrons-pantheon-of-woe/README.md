# Pantheon of Woe contribution draft

[Proposed mechanics](proposals.json) covers four 40kdc placeholders. Each entry includes the stable ability ID, expected behavior, edge cases, and typed workbench proposals ready for review. Offsets identify spans only in the private reference with the listed hash.

The Cascade draft passed the compiler's automated gates. Its two trigger nodes currently act as alternatives, so the compiler result needs a single window tied to the destroyed model's impending roll. The other three entries still need the annotations listed in their `compiler_status` fields.

Once the mechanics and rendered descriptions have been reviewed, the workbench can write the approved enrichment and any associated target restrictions. The upstream PR will carry the generated data and its validation results. [40kdc authoring workflow](https://github.com/wn-mitch/40kdc-data/blob/main/SEMANTIC_AUTHORING.md)
